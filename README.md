# Даниил Игнатьев — сайт-визитка

Браузерные игры, сделанные с AI-агентами: https://common-ka.github.io/

Статический сайт без сборки: `index.html`, `styles.css`, `main.js` и данные игр в `games.js`. Публикуется через GitHub Pages: любой push в ветку `main` обновляет сайт через 1–2 минуты.

## Как добавить игру

1. Положи обложку 16:9 в `assets/img/covers/` в двух размерах: `<id>-640.webp` и `<id>-1280.webp` (ширина 640 и 1280 px).
2. Открой `games.js` и скопируй любой блок в списке `games`. Порядок блоков — порядок карточек на сайте.
3. Поменяй поля и сохрани. Готово.

Быстро поправить можно прямо в браузере: на странице репозитория нажми `.` — откроется редактор.

### Поля карточки

| Поле | Что это | Обязательно |
| --- | --- | --- |
| `id` | Короткое имя латиницей, совпадает с именем файлов обложки | да |
| `title` | Название игры | да |
| `status` | `released` — вышла (оливковый), `launch` — запуск (охра), `dev` — в разработке (синий) | да |
| `statusText` | Подпись статуса, например `Вышла · Playgama и Yandex Games` | да |
| `genre` | Жанр одной строкой | нет |
| `hook` | Одна-две фразы: что делает игрок | нет |
| `rating` | Строка рейтинга, например `★ 4,3 / 5 на Playgama · 96 оценок` | нет |
| `cover` | `{ image: 'assets/img/covers/<id>', alt: 'описание обложки' }`; `position: 'left center'`, если важная часть обложки у края. Без обложки: `{ placeholder: 'voxels' }` | да |
| `links` | Кнопки: `{ label: '▶ CrazyGames', url: '…', primary: true }`. Главная кнопка одна | нет |
| `soon` | Пунктирные плашки «скоро», например `['Скоро на Playgama']` | нет |
| `stack` | Теги технологий | нет |
| `how` | Раскрывающийся блок «Как сделано»: `notes` (карточки «заголовок + текст»), `shots` (скриншоты) или `extra` (отдельный подблок вроде Playable Ad) | нет |

Скриншот: `{ src: 'assets/img/….webp', w: 390, h: 700, alt: '…', caption: 'Hook' }`.

### Блок «Сейчас»

Строки над карточками — список `now` в начале `games.js`: `{ label: 'Сейчас', text: '…' }`.

## Структура

```
index.html        разметка страницы
styles.css        стили
main.js           небо из граней, литография, сборка карточек из games.js
games.js          данные игр — правится чаще всего
assets/logo/      знак «Квадрат-пиксель» и фавиконка
assets/img/       обложки и скриншоты
```

Брендбук (палитра, шрифты, компоненты, логотип) ведётся отдельно в Claude.
